## 화면

기존 다섯 탭 유지. 마이 예산·소비, 피드 더보기의 소득대 평균, 기록의 월별 요약·날짜별 거래는 API 연결. 시연 모드와 나머지 콘텐츠는 고정 데이터입니다. 실제 API E2E를 포함해 데스크톱·모바일 16개 통과. 6월 소비 72,600원·평균 187,600원·24명, 6월 30일 거래 12,000원 대조. 페이지 경계는 별도의 HTTP 대역 21건입니다.
