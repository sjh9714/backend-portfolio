# 새 포트폴리오 확인 기록

확인일: 2026-10-04. `codex/portfolio-cases`의 정적 산출물을 확인했다. 기존 사이트의 main과 Vercel 프로젝트는 개편 대상으로 사용하지 않는다.

## 화면과 콘텐츠

- 포트폴리오 구성은 `fca83d3`를 기준으로 복원했다. 홈의 소개·주력 기술·대표 프로젝트·추가 프로젝트·연락처, 대표 프로젝트의 화면·목적·역할·사례·결과·기술을 유지했다.
- 채팅, ETA, 정산 Gateway는 추가 프로젝트로 연결한다. 기존 프로젝트 경로와 7개 사례 앵커는 유지한다.
- 상세는 프로젝트 소개와 역할·범위, 사례 탐색, 기존 문제 해결 항목, 구현 기능, 서비스 화면과 실행 순서를 유지한다. 질문형 제목이나 블로그형 본문으로 재배치하지 않았다.
- FinMate는 실제 측정한 네 조회 대안의 이유·추가 저장 비용·전체 재생성 비용을 보강했다. 나머지 사례는 가짜 비교 선택지 대신 코드로 확인한 구현 이유를 설명한다. 예매는 선점·결제·취소·만료의 잠금과 상태 변경 순서를 보강했다.
- FinMate와 ETA는 기존 팀 기록과 개인 보강의 담당 범위를 구분한다. 구현·시연 범위는 상단과 화면 옆, 측정 조건은 결과 옆, 기술적 한계는 사례 끝에 두고 반복 문장을 줄였다.
- 토스테크의 색상·글자 위계·여백·이미지 모서리를 시각 참고로 사용했다. 강한 세로선과 기본 밑줄을 줄이고 결과를 옅은 회색 면으로 구분했다. 프로젝트와 사례의 내용은 스타일에 맞춰 다시 쓰지 않았다.
- 실제 운영 성과와 합성 데이터·로컬 관측을 구분한다. 앞 단계에서 원자료와 대조한 FinMate의 160개 SQL 측정 표본을 그대로 사용했다. 인덱스 25,460,736 bytes, 월 집계 1,671,168 bytes, 전체 재생성 351.305ms는 같은 기록에서 가져왔다. 이번 콘텐츠 보강에서 백엔드 시험이나 성능 실험을 다시 실행하지 않았다.
- 1440px·1280px·390px·375px에서 홈과 5개 상세의 첫 화면 및 전체 화면을 캡처했다. 홈의 대표 프로젝트와 상세 상단의 역할·범위가 보이며 본문과 표가 가로로 넘치지 않는다. 홈의 프로젝트 링크는 상세 맨 위로 이동한다. 상세의 사례 탐색과 이력서의 사례 링크는 기존 앵커로 연결한다.
- 대표 프로젝트는 이미지·프로젝트명·사례 제목에서 모두 상세로 이동한다. 이미지 클릭으로 홈이 조금 스크롤된 경우에도 상세를 처음부터 열도록 이 세 링크는 일반 문서 이동을 사용한다. 기존 진입 E2E에서 각 링크를 눌러 URL·스크롤 0·소개 제목을 확인했다.
- 이전의 큰 이름 애니메이션, WebGL 갤러리, 강제 스크롤은 제거했다. Pretendard, 흰색 바탕과 파란색 강조를 유지했다.
- FinMate 앱의 기존 화면과 다섯 탭, 각 서비스 README는 수정하지 않았다. 홈 이미지는 보존된 실제 화면의 표시 영역만 조정했다.

Node.js 22.23.2, Next.js 16.2.10, Playwright 1.61.1을 사용했다. 새 분기·표 검사는 수정 전 빌드에서 실패하고 수정 후 통과했다. FinMate 표의 네 행에 조회 시간과 저장 공간이 올바르게 연결되는지 검사했으며, 비교 비용이 없는 표는 기존 두 열을 유지한다.

PDF 도구 원본 대조는 unchanged였다. PDF 본문 글자 크기는 14 CSS px이며 A4 2쪽 전체를 렌더해 문장·여백·사례 링크 3개를 확인했다. 프로젝트 설명은 페이지 사이에서 잘리지 않는다. 콘텐츠뿐 아니라 인쇄 CSS와 폰트도 PDF 갱신 해시에 포함한다.
