# 새 포트폴리오 확인 기록

확인일: 2026-10-03. `codex/portfolio-cases`의 정적 산출물을 확인했다. 기존 사이트의 main과 Vercel 프로젝트는 개편 대상으로 사용하지 않는다.

## 화면과 콘텐츠

- 홈의 대표 프로젝트는 FinMate와 콘서트 예매다. 각 행에 서비스 목적, 담당 역할, 판단, 결과와 근거를 표시한다.
- 채팅, ETA, 정산 Gateway는 추가 프로젝트로 연결한다. 기존 프로젝트 경로와 7개 사례 앵커는 유지한다.
- 실제 운영 성과와 합성 데이터·로컬 관측을 구분한다. FinMate의 새 측정 160개 표본에서 p50·p95를 별도로 계산해 원자료와 대조했다.
- 데스크톱의 홈·사례 본문을 브라우저로 확인했다. 375px 모바일 캡처에서는 첫 화면에 대표 사례 제목이 보이며 본문과 표가 가로로 넘치지 않는다.
- 이전의 큰 이름 애니메이션, WebGL 갤러리, 강제 스크롤은 제거했다. Pretendard, 흰색 바탕과 파란색 강조를 유지했다.

Node.js 22.23.2, Next.js 16.2.10, Playwright 1.61.1을 사용했다. PDF 본문 글자 크기는 14 CSS px이며 프로젝트 한 편의 문장이 페이지 사이에서 잘리지 않도록 실제 렌더를 확인했다. 콘텐츠뿐 아니라 인쇄 CSS와 폰트도 PDF 갱신 해시에 포함한다.

## 모바일 Lighthouse

로컬 정적 서버, Lighthouse 12.8.2의 기본 모바일 설정이다. 예열 1회 후 페이지별 1회 측정했으며 실사용자의 현장 성능을 뜻하지 않는다.

원본 Lighthouse JSON은 CI 실행의 `lighthouse-reports` 산출물로 보존한다. 로컬 보고서는 `lh-*.json`이며 Git에서 제외한다.

## 배포 범위

기존 계정의 Vercel Hobby가 active임을 배포 전에 확인했다. [Hobby 정책](https://vercel.com/docs/plans/hobby)에 따라 정적 사이트만 배포하며 요금제 변경, 유료 부가 기능, 신규 DB·가상 머신을 만들지 않는다.

새 사이트는 `sjh9714-backend`, 기존 사이트는 `sjh9714`라는 별도 프로젝트다. FinMate의 공개 화면은 고정 데이터 시연이며, 실제 API 연결은 로컬 Compose에서 검증했다. 공개 백엔드가 실행되고 있다는 뜻으로 작성하지 않는다.
