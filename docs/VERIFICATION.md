# 새 포트폴리오 확인 기록

확인일: 2026-10-03. `codex/portfolio-cases`의 정적 산출물을 확인했다. 기존 사이트의 main과 Vercel 프로젝트는 개편 대상으로 사용하지 않는다.

## 화면과 콘텐츠

- 토스테크만 디자인 기준으로 사용했다. 홈의 FinMate·예매 사례는 문제를 설명하는 제목, 짧은 요약과 실제 화면을 하나의 링크로 묶는다. 역할·검증 결과·기술 목록은 상세로 옮겼다.
- 채팅, ETA, 정산 Gateway는 추가 프로젝트로 연결한다. 기존 프로젝트 경로와 7개 사례 앵커는 유지한다.
- 상세는 700px 폭의 한 열 본문이며, 사례별 소제목 아래에서 기존 문단·비교표·구조도·출처를 읽는다. 모든 문단과 근거가 한 번씩 배치되는지 검사한다.
- 실제 운영 성과와 합성 데이터·로컬 관측을 구분한다. 앞 단계에서 원자료와 대조한 FinMate의 160개 SQL 측정 표본을 그대로 사용했다. 이번 화면 개편에서 백엔드 성능 실험을 다시 실행하지 않았다.
- 1440px·1280px·390px·375px에서 홈과 5개 상세의 첫 화면 및 전체 화면을 캡처했다. 첫 화면에 대표 제목과 상세의 첫 문제 설명이 보이며 본문과 표가 가로로 넘치지 않는다.
- 이전의 큰 이름 애니메이션, WebGL 갤러리, 강제 스크롤은 제거했다. Pretendard, 흰색 바탕과 파란색 강조를 유지했다.
- FinMate 앱의 기존 화면과 다섯 탭, 각 서비스 README는 수정하지 않았다. 홈 이미지는 보존된 실제 화면의 표시 영역만 조정했다.

## 배포 범위

기존 계정의 Vercel Hobby가 active임을 배포 전에 확인했다. [Hobby 정책](https://vercel.com/docs/plans/hobby)에 따라 정적 사이트만 배포하며 요금제 변경, 유료 부가 기능, 신규 DB·가상 머신을 만들지 않는다.

새 사이트는 `sjh9714-backend`, 기존 사이트는 `sjh9714`라는 별도 프로젝트다. FinMate의 공개 화면은 고정 데이터 시연이며, 실제 API 연결은 로컬 Compose에서 검증했다. 공개 백엔드가 실행되고 있다는 뜻으로 작성하지 않는다.
